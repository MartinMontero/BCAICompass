# seed-summary

Generated by `research\audit\Build-Seed.ps1` from artifact A. Source tag on every record: `bc-ai--ecosystem-map@database-backup-2025-08-04`.

`research\seed.json` is **a list of names to go and check.** It is not a dataset,
it is not published, and nothing in it is built into the site. No `funding`,
`description`, `keyPeople`, `yearFounded`, `email` or `status` value from artifact A
is carried forward. No region, coordinate or blurb is invented. Missing is `null`.

### Notes on three of those counts

- **`person-not-org` = 0.** Not an oversight. A personal-name heuristic returned 122
  candidates; reading all 122 found no people at all -- only report fragments and
  genuine two-word company names (`Moment Energy`, `General Fusion`). Artifact A
  does not appear to contain person-rows. See AUDIT.md 2.6.5.
- **`product-not-org` = 4.** Curated by eye, not pattern-matched. The pattern flagged 9,
  of which 4 were report fragments already counted elsewhere and 1 (`CoPilot AI`)
  is a real company. Only the 4 judged genuine products carry the flag.
- **`duplicate-domain` = 17.** Excludes shared aggregator domains (linkedin.com, meetup.com, eventbrite.ca, eventbrite.com, facebook.com, notion.site, github.io),
  because many unrelated organisations legitimately share those and a collision
  there is not evidence of duplication.

## The flag set cannot express the largest defect class

262 artifact-A rows are lines lifted from a markdown report rather than entities --
`Headquarters:`, `CEO:`, `Team Size:`, `Talent Mapping`, `Year Founded`,
`batch-15-formatted.json` (AUDIT.md 2.6.4). That class is larger than every other
defect class combined, and **the closed flag set has no flag for it.**
`person-not-org` and `product-not-org` are the nearest and both are wrong.

The closed set is honored exactly as specified: those rows carry `no-url`, which is
true, and nothing else. The consequence is that **seed.json alone understates the
damage by design**, so the count is carried here instead. Recommended for a future
revision of the schema: add `not-an-entity`.
